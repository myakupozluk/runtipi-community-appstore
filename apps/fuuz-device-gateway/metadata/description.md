# Fuuz Device Gateway

A secure gateway that connects on-premise devices, PLCs, and data sources to the Fuuz Cloud for seamless, real-time integration.

## Overview
* **Category:** Network, Development, Data
* **Default Port:** `5500` (Internal: `5500`)
* **Architectures:** amd64, arm64
* **Author / Project:** portainer/templates
* **Source:** [https://github.com/portainer/templates/](https://github.com/portainer/templates/)

## Features & Configuration
This application is packaged for Runtipi with Dynamic Compose (Schema Version 2).
Data is persistently stored in your Runtipi storage path (`${APP_DATA_DIR}`).
You can expose this application through your custom domain via Runtipi's Traefik reverse proxy.
