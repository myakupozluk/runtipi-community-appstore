# Seawise.io Client

Share self-hosted apps with family and friends, no port forwarding. Client for the Seawise.io service (free account required).

## Overview
* **Category:** Network
* **Default Port:** `9993` (Internal: `9993`)
* **Architectures:** amd64, arm64
* **Author / Project:** seawise-io/seawise-client
* **Source:** [https://github.com/seawise-io/seawise-client/](https://github.com/seawise-io/seawise-client/)

## Features & Configuration
This application is packaged for Runtipi with Dynamic Compose (Schema Version 2).
Data is persistently stored in your Runtipi storage path (`${APP_DATA_DIR}`).
You can expose this application through your custom domain via Runtipi's Traefik reverse proxy.
