# AI Marketplace Monitor

Watch Facebook Marketplace for the items you want, rate each new listing with AI, and get notified of good deals. Source: https://github.com/BoPeng/ai-marketplace-monitor

## Overview
* **Category:** Media, Development, Productivity
* **Default Port:** `8467` (Internal: `8467`)
* **Architectures:** amd64, arm64
* **Author / Project:** BoPeng/ai-marketplace-monitor
* **Source:** [https://github.com/BoPeng/ai-marketplace-monitor/](https://github.com/BoPeng/ai-marketplace-monitor/)

## Features & Configuration
This application is packaged for Runtipi with Dynamic Compose (Schema Version 2).
Data is persistently stored in your Runtipi storage path (`${APP_DATA_DIR}`).
You can expose this application through your custom domain via Runtipi's Traefik reverse proxy.
