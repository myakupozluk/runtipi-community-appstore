# LibreDB Studio

Self-hosted database IDE you use from a browser, covering forty-two engines - PostgreSQL, MySQL, Oracle, SQL Server, MongoDB, Redis, ClickHouse, Cassandra, Elasticsearch and more - with a schema browser and query history on all of them, and ER diagrams and EXPLAIN plans wherever the engine declares keys or returns a plan. Source: https://github.com/libredb/libredb-studio

## Overview
* **Category:** Development, Data, Games
* **Default Port:** `3006` (Internal: `3000`)
* **Architectures:** amd64, arm64
* **Author / Project:** libredb/libredb-studio
* **Source:** [https://github.com/libredb/libredb-studio/](https://github.com/libredb/libredb-studio/)

## Features & Configuration
This application is packaged for Runtipi with Dynamic Compose (Schema Version 2).
Data is persistently stored in your Runtipi storage path (`${APP_DATA_DIR}`).
You can expose this application through your custom domain via Runtipi's Traefik reverse proxy.
